Key Innovations

Built for Modern Hardware & Zero Friction

Solving the historic bottlenecks of volunteer distributed computing platforms.

🪟

The Windows "Holy Grail"

Windows adoption usually dies on WSL2 or Docker Desktop setups. Speedboat compiles to a pure Go static binary (agent.exe) with zero external dependencies, no CGO, and no admin rights needed.

⚡

Silent In-Memory JIT

Embedded wazero runtime compiles WebAssembly bytecode directly into native x86-64 and ARM64 machine instructions in memory, achieving 85–90% of native speed with complete software isolation.

🔬

The Standard Stream Contract

Scientists write normal scientific code without distributed systems headaches: Generator (emits task JSON), Logic (calculates result JSON from stdin), and Reducer (aggregates verified batches).

🛡️

Zero-Trust Sandboxing

Workloads run inside strict memory jails or rootless Linux namespaces. Faulty scientific code triggers runtime traps, killing the task instantly while leaving the volunteer's computer rock-solid.

⚖️

FP Determinism & Anti-Cheating

Floating-point differences between architectures are resolved using epsilon-tolerance comparison and 3-way majority consensus. Spot-check trap tasks catch spoofers.

🎮

Gamified Pilot Telemetry

Volunteer retention thrives on real-time feedback: dynamic FLOPS credit tickers, cockpit avionics HUDs, and 5-tier Pilot Rank badges from Cadet to Mach-10 Grand Architect.
