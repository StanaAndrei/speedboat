
Example workflow in the easiest case(container build and cli agent):
[Scientist / Master Node]                                  [Technical Volunteer / Agent]
            │                                                              │
   1. Bake Docker Image & push to Registry                                 │
   2. Run generator.py -> emit tasks                                       │
   3. Push tasks to JetStream WorkQueue Stream                             │
   4. Publish project announcement (NATS URL + Project ID on internet)     │
            │                                                              │
            │ ── (Volunteer receives URL & Project ID via CLI/env) ──────> │
            │                                                              │
            │ <── Pull Image from Registry via Apptainer ───────────────── │
            │ <── JetStream Consumer Pull (Fetch 1 Task, auto-locks) ───── │
            │                                                              │
            │                                               [Runs Container]
            │                                               JSON via stdin -> logic -> stdout
            │                                                              │
            │ <── Publish Result to `results.<project_id>` ─────────────── │
            │ <── Send JetStream ACK (Task deleted from pending queue) ─── │
            │                                                              │
   5. Master verifies consensus / redundancy                               │
   6. Pipe verified results to reducer.py
