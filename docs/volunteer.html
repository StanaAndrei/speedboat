Lend Your Idle Cycles.
Choose Your Compute Channel.

Speedboat supports three distinct volunteer tiers: an ultra-light single-binary desktop GUI, a headless CLI for 24/7 server clusters, or zero-install browser Web Workers where volunteers simply open a project link to begin computing.

Primary Worker Option

The Single-Binary Desktop Experience

Download a 15MB executable, run it with zero admin privileges, and instantly crunch scientific models with hardware acceleration.

The Windows "Holy Grail"

Zero Dependencies. No Admin Rights. Pure Static Go.

Traditional volunteer platforms like BOINC or Folding@home historically suffer from broken WSL2 configurations, Docker Desktop licensing hurdles, and intrusive driver installations. Speedboat’s Windows client (agent.exe) is compiled statically in pure Go:

~15 MB
Single Binary Size
⚡ Silent In-Memory JIT

Embedded wazero runtime compiles WebAssembly directly to native x86-64 machine instructions in RAM. 85–90% native speed with zero disk overhead.

🛡️ Memory-Jail Security

Zero file-system access (cannot read your personal files or Registry) and zero network exfiltration capabilities.

🚀 Dual-Engine Switching

Runs in Lite Mode (WASM) by default, or flips to Heavy Mode (rootless container) if GPU/AVX-512 hardware acceleration is enabled.

Run as Background Service (systemd)

          

            Keep your volunteer agent active across reboots on Linux servers:
          


          

            

              /etc/systemd/system/speedboat.service
              
            

            
[Unit]
Description=Speedboat Volunteer Compute Worker
After=network.target

[Service]
Type=simple
User=speedboat
Restart=always
RestartSec=5
ExecStart=/usr/local/bin/speedboat-agent run --project-id prime-counter --nats-url nats://localhost:4222 --runtime auto

[Install]
WantedBy=multi-user.target

Browser Web Worker: Zero Installation Required

          

            No downloads, no executables, no setup. When a research team or master node shares a project link, volunteers simply open that URL in any modern browser—the tab immediately initializes the Web Worker and crunches tasks in the background with zero setup.
