# Speedboat 🚤

A modern, high-performance volunteer computing platform written in Go. Speedboat decouples scientific orchestrators (**Master Node**) from untrusted volunteer workers (**Native Agent**, **Desktop GUI**, and **Browser Web Worker**) using **NATS** and isolated execution sandboxes (**Wazero WASM JIT**, **Rootless Apptainer**, and **Docker**).

---

## Architecture Overview

* **Master Node (`build/speedboat-master`):** Distributes tasks via NATS work queues, validates consensus results, aggregates batches with reducers, and serves WASM payloads and web workers over an embedded HTTP server.
* **Desktop GUI Agent (`build/speedboat-gui`):** Ultra-lightweight (~15 MB) cross-platform GUI built with **Wails v2** and **Preact**, featuring an embedded **Wazero** pure-Go JIT runtime (Tier 1). Supports pasting invite links directly, dynamic multi-thread CPU sliders, and live task throughput monitoring with zero external runtime dependencies.
* **CLI Headless Agent (`build/speedboat-agent`):** Portable headless binary for servers and headless volunteer workers.
* **Browser WASM Worker:** Zero-install web worker tab connecting to NATS over WebSockets (`nats.ws`).

## Development Prerequisites Across Devices

### 1. Linux (Ubuntu 24.04+, Linux Mint 22+, Debian)

Wails on Linux requires GTK3 and WebKit2GTK header packages:

```bash
# System libraries
sudo apt update
sudo apt install -y build-essential pkg-config libgtk-3-dev libwebkit2gtk-4.1-dev

# Go (1.22+) and Node.js (v18+)
# Install Wails CLI v2:
go install github.com/wailsapp/wails/v2/cmd/wails@latest
```

Ensure `~/go/bin` is in your `$PATH`:
```bash
export PATH=$PATH:$(go env GOPATH)/bin
```

### 2. macOS (Apple Silicon / Intel)

macOS uses the native Apple WebKit framework built into the OS (no GTK or WebKit2GTK libraries required).

```bash
# Install Go, Node, and Wails via Homebrew:
brew install go node
go install github.com/wailsapp/wails/v2/cmd/wails@latest
```

Ensure `~/go/bin` is in your `$PATH`:
```bash
export PATH=$PATH:$(go env GOPATH)/bin
```

Install frontend dependencies before compiling the GUI:
```bash
cd gui/frontend && npm install && cd ../..
```

### 3. Windows (Windows 10 / 11)

Windows uses the built-in Microsoft Edge WebView2 runtime. No C++ or GTK libraries are needed.

1. Install [Go](https://go.dev/dl/) and [Node.js](https://nodejs.org/).
2. Install Wails CLI:
   ```powershell
   go install github.com/wailsapp/wails/v2/cmd/wails@latest
   ```

## Building the Project

Use the `Makefile` to compile all platform binaries:

```bash
# Build master CLI, agent CLI, and the Wails Desktop GUI:
make build

# Or build the GUI for the current OS (auto-detects macOS vs Linux):
make build-gui

# Specifically build the macOS GUI (.app bundle & standalone binary):
make build-mac

# Specifically build the Linux GUI (WebKit2GTK):
make build-linux

# Specifically build the Windows GUI executable:
make build-win
```

Built binaries will be located under `./build/`:
* `build/speedboat-master`
* `build/speedboat-agent`
* `build/speedboat-gui` (executable, directly runnable from terminal)
* `build/speedboat-gui.app` (macOS application bundle, generated on macOS)

## Quickstart: Running a Cluster & Desktop GUI

### 1. Start NATS Cluster & Services

```bash
cd examples
docker compose up -d
cd ..
```

### 2. Launch the Master Orchestrator

```bash
./build/speedboat-master run \
  --project-dir examples/prime-cnt \
  --no-build \
  --wasm examples/prime-cnt/logic.wasm
```

The master node generates tasks and displays the volunteer invite URL:
```text
🌐 [WASM Web Worker] Volunteer page available at:
👉 http://192.168.1.138:3000/?project=prime-counter&nats=ws://192.168.1.138:8080
```

### 3. Launch the Desktop GUI Agent
 
 ```bash
 # Launch from terminal:
 ./build/speedboat-gui
 
 # Or on macOS, launch the application bundle:
 open build/speedboat-gui.app
 ```

1. **Paste Link:** Paste the URL generated by the master node into the input box (or click **Paste Link** to auto-read from clipboard).
2. **Preview:** The app verifies the project name and connectivity with the master node.
3. **Select CPU Threads:** Use the CPU slider to choose how many worker goroutines to allocate.
4. **Start Computing:** Wazero JIT-compiles the payload in-memory and crunches tasks at near-native speed. Live progress, throughput, and logs appear in real time!
